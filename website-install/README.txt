AUXILIUM WEBSITE - GHL PASTE PACK
=================================
Full step-by-step instructions are in the "Auxilium Website: GHL Install + Google Launch Runbook" doc.

00-website-settings-head-code.html  -> Website Settings > Tracking code > Header (ONCE, applies to all pages)
NN-page/1-page-code.html            -> one Custom Code (HTML) element, full-width section, zero padding
NN-page/2-page-head-schema.html     -> that page's Settings > Tracking code > Header
NN-page/3-seo-settings.txt          -> that page's SEO meta data (title, description, keywords, social image)
og-image.png                         -> upload as the Social Image on every page
favicon-mark.svg                     -> export as a 512px PNG and set as the website favicon

Placeholders to check before publishing:
 - 09-book-a-demo: swap the dashed "Calendar loads here" box for your GHL calendar embed
 - FAQ "How does Auxilium handle data and GDPR?" says every gym signs a DPA before go-live. Make sure that is true.
